Hermes 차세대 4대 하네스 엔진 2026-10-28 최신

단순한 프롬프트는 에러가 나면 멈추지만, 4대 하네스 엔진이 결합된 Hermes Agent는 오류를 스스로 검증하고 지식을 영구 자산화합니다.

🛡️ 엔진 1
Verify-on-Stop 종료 가드

AI의 "다 했습니다" 거짓 보고 원천 차단. 실제 파일 생성·테스트 PASS 증거가 있어야만 세션 종료 승인.

⚡ 엔진 2
Living Memory 초고속 인출

구판·폐기 문서는 은퇴(Retired) 격리하여 환각 방지. 살아있는 정본만 6,000자 이내 핀포인트 인출 (토큰 90% 절감).

🧩 엔진 3
FairyClaw 스킬 런타임

장황한 말 대신 한 줄 CLI 명령어로 리서치·요약·검수를 무인 자동 실행하는 정형화 스킬 체계.

🔄 엔진 4
전파 채무 추적기 (Debt Tracker)

상위 헌법이나 세법/상품 스펙이 바뀌었을 때, 하위 마케팅 원고와 기획서가 누락 없이 함께 갱신되도록 추적.

마스터 프롬프트 전문

지금 평소 쓰시던 메인 AI(Claude, ChatGPT, Cursor 등) 대화창에 아래 내용을 그대로 붙여넣으세요: 

당신은 나의 1인 비즈니스 시스템을 혁신하는 [수석 AX(AI Transformation) 시스템 아키텍트]입니다.

내가 지금까지 당신과 나눈 대화, 진행 중인 사업 프로젝트, 작성 중인 문서 맥락을 종합 분석하여, 
단순한 '대화창 복붙 셔틀'에서 벗어나 백그라운드에서 스스로 정보를 검증하고 내 서재로 직배달하는 [Hermes Agent 1인 무인 업무 시스템]을 내 상황에 맞춰 완벽하게 구축해 주세요.

이번 세팅에는 최신 2026 Hermes 4대 런타임 하네스 엔진(Verify-on-Stop 가드, Living Memory 초고속 인출, FairyClaw 스킬 런타임, 전파 채무 추적)이 반드시 포함되어야 합니다.

아래 4가지 단계를 순서대로 구체적이고 바로 쓸 수 있게 작성해 주세요:

---

### [STEP 1] 2층 분리 폴더 구조 (Thin Cockpit + Data Vault)
- 지금까지 우리가 나눈 대화를 바탕으로, 내가 집중하고 있는 2~3대 핵심 사업 영역을 정의해 주세요.
- 사람이 보는 가벼운 메모/조종석(Obsidian/마크다운)과 데이터가 쌓이는 영구 볼트를 분리한 실전 디렉토리 트리(Directory Tree)를 짜주세요:
  - 00_Inbox/ (아이디어·회의록·웹링크 무마찰 인입)
  - 01_SSOT/ (단일 진실 원천 규정 및 브랜드 헌법)
  - 02_Projects/ (진행 중인 프로젝트별 조종석 노트)
  - 03_Ledger/ (지식 원장 및 실행 장부 SQLite/JSON)
  - 99_Archive/ (구판·폐기 문서가 영구 격리되는 은퇴 보관소)

---

### [STEP 2] 우리 팀 마스터 헌법 (AGENTS.md)
- Hermes Agent가 내 컴퓨터에서 자율적으로 일할 때 지켜야 할 [절대 행동 지침 4대 규칙]을 명문화해 주세요:
  1. [Zero-Question Autonomous]: "어떻게 할까요?", "A안과 B안 중 골라주세요" 같은 사소한 질문으로 사람의 집중을 깨지 말고, 최선의 권장안(Recommended Option)을 스스로 판단해 끝까지 완주할 것.
  2. [Fail-Closed & Zero-Fabrication]: 확인되지 않은 데이터, 결측치, 모르는 수치는 0으로 지어내지 말고 반드시 [미측정] 또는 [미연결]로 표기할 것.
  3. [토큰 90% 다이어트]: 긴 대화를 전부 프롬프트에 넣지 말고, 필요한 살아있는 정본 자료만 6,000자 이내로 핀포인트 인출해 컨텍스트 낭비와 환각을 원천 차단할 것.
  4. [3대 블록 사후 보고]: 작업 완료 후 장황한 변명 대신 반드시 [1. 수행 결과 / 2. 자동 채택 근거 / 3. 롤백(되돌리기) 방법] 3가지만 간결하게 보고할 것.

---

### [STEP 3] Hermes 차세대 4대 하네스 엔진 구현 명세
- 내 업무 특성에 맞춰 아래 4대 하네스를 어떻게 구성할지 구체적인 스펙과 작동 방식을 정의해 주세요:
  1. [Verify-on-Stop 종료 가드]: AI가 "다 했습니다"라고 말만 하고 끝내는 것을 원천 차단. 실제 파일 생성 여부, 글자 수 규격, 린터 점수 등 '기계적 증거'가 확인되어야만 세션을 종료하는 가드레일.
  2. [Living Memory 초고속 인출]: 폐기된 옛날 문서는 은퇴(Retired) 처리하여 읽지 못하게 차단하고, 살아있는 정본 지식만 빠르게 인출하는 인덱싱 규칙.
  3. [FairyClaw 스킬 런타임]: 반복되는 리서치, 요약, 검수 작업을 매번 설명하지 않고 python run_task.py --mode research 형태의 1줄 정형 스킬로 모듈화하는 방안.
  4. [전파 채무 추적기 (Propagation Debt Tracker)]: 상위 지침서나 가격, 제품 스펙이 바뀌었을 때 하위 마케팅 원고나 기획서가 누락 없이 함께 갱신되도록 추적하는 동기화 규칙.

---

### [STEP 4] 오늘 바로 실행할 '첫 번째 Hermes 무인 태스크'
- 내가 지금 당장 터미널이나 AI 대화창에 던져서 테스트할 수 있는 가장 효과적인 [첫 번째 실행 명령어와 프롬프트]를 하나 제시해 주세요.
  (예: "내 사업 관련 시장 리포트/경쟁사 자료 3개를 수집·대조하여 00_Inbox에 팩트 요약표를 납품하는 태스크")

---
