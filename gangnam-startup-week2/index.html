강남구 초기 창업자 과정 2주차 - AI 네이티브 컴퍼니 구축과 폴더 기반 업무 환경 강의 정리

질문할 때마다 배경을 다시 설명해야 하는 일회성 웹 채팅창을 넘어, 내 컴퓨터의 로컬 폴더에 회의와 업무 기록을 마크다운(.md)으로 차곡차곡 쌓는 '폴더 기반 AI 협업' 환경을 구축하고, AI 성숙도 5단계 자가진단과 보안 가드레일로 1인 및 초기 스타트업의 업무를 자동화한다.

1. 강의 핵심 요지

1. 강의 요지 (AI 네이티브 컴퍼니와 폴더 기반 작업 환경)

1) 웹 채팅창을 넘어 '로컬 폴더 기반 지식 베이스'로 (컨텍스트 휘발 극복)

• 일회성 웹 채팅창의 근본적 한계:

• 브라우저 채팅창에 매번 회사 소개, 상품 설명, 배경을 길게 복사-붙여넣기하면 대화가 길어질 때 이전 맥락을 잊어버리는 '컨텍스트 컴팩션(Context Compaction)' 현상이 일어납니다.

• 채팅창이 닫히면 이전의 질문과 답변이 일회성으로 휘발되어, 사내 데이터가 누적되지 못하고 매번 원점에서 다시 시작해야 합니다.

• 로컬 폴더 기반 전사(Transcription) 프로세스:

• 내 컴퓨터의 로컬 폴더(옵시디언)에 회의록, 고객 상담, 업무 기록을 마크다운(.md) 파일로 차곡차곡 모아두면, AI가 해당 폴더 전체를 하나의 '살아있는 기억 저장소'로 인식합니다.

• 회의 녹음 ➔ 텍스트 전사(STT) ➔ 마크다운(.md) 변환 ➔ 지정 폴더 자동 적재라는 '전사 프로세스'가 AI 네이티브 조직으로 진화하는 첫 번째 기초 체력입니다.

2) 우리 회사의 AI 성숙도 5단계 자가진단

강사가 제시한 조직의 AI 활용 5단계 성숙도 사다리입니다. 우리 회사가 지금 어느 단계에 있는지 점검해 볼 수 있습니다.

• Lv.0 (일회성 질문): 필요할 때마다 채팅창을 열고 회사 배경 설명부터 다시 복붙한다.

• Lv.1 (기록 축적): 회의, 고객 피드백, 결정 사항이 한 로컬 폴더에 마크다운 파일로 쌓이고 있다.

• Lv.2 (기준 확립): "우리는 이렇게 일한다"는 업무 지침서(SOP)가 있고 AI가 이를 읽고 기준대로 답한다.

• Lv.3 (지시 간소화): 매주 반복되는 업무를 지시서 한 줄로 넘기고, 지시서가 점점 짧아진다(자동 리포트).

• Lv.4 (출처 투명성): 회사 밖에서도 접속되는 공유 주소가 있고, AI가 내 숫자를 공식 출처와 함께 말할 수 있다.

• Lv.5 (팀 협업 자동화): 사람이 매번 켜지 않아도 정해진 시각에 시스템이 돌고, 팀 전체가 메신저 채널에서 함께 쓴다.

3) 사람의 개입(Human-in-the-Loop) — AI 에이전트 무한 루프 방지

• 자율 실행의 환상 경계:

• AI 에이전트에게 루프만 무한정 돌려놓는다고 해서 올바른 결과가 저절로 나오지 않습니다. 오히려 잘못된 방향으로 질주해 엉뚱한 거짓 답변(할루시네이션)을 키울 위험이 큽니다.

• 사람의 트리거와 최종 승인:

• "사람의 아이디어가 처음 방아쇠(Trigger)를 당기고, 중간 기준을 승인(Approve)하며 최종 방향을 이끌어야 한다"는 점이 실무 자동화의 절대적인 안전 원칙입니다.

4) 초기 보안 가드레일 — '기본 차단, 점진적 허용'

• 데이터 보안 기본 원칙:

• AI 도구를 사내에 도입할 때 회사 기밀, 재무 원장, 고객 개인정보가 노출되지 않도록 처음에는 접근 권한을 닫아두고 안전성이 검증된 문서부터 하나씩 권한을 열어주어야 합니다.

• 로컬 에디터 환경의 통제력:

• 외부 클라우드에 무분별하게 업로드하기보다, 로컬 터미널이나 에디터(Cursor, VS Code 등) 환경을 활용하면 데이터가 외부로 유출되는 경로를 사람이 통제하기 훨씬 유리합니다.

2. 핵심 관점 대조 (일회성 웹 채팅 vs 로컬 폴더 기반 AI 협업)

3. 수강생 실천 기록 (1인 빌더의 폴더 적재 3단계 실천)

강의에서 배운 방식을 제 실제 1인 빌더 업무에 대입해 보며 실천한 3가지 과정입니다.

1. 내 업무 폴더 생성 및 옵시디언 연결 (Lv.1 달성):

• 회의와 강연 메모, 외부 학습 기록을 마크다운 파일(.md)로 로컬 컴퓨터 한곳에 모아 AI가 읽을 수 있는 지식 기반을 세웠습니다.

2. '우리는 이렇게 일한다' 기준 문서 1장 작성 (Lv.2 달성):

• AI에게 매번 똑같이 설명하던 '수치 인용 원칙', '금지 표현', '보고서 포맷'을 1장짜리 업무 지침서(SOP) 파일로 확정했습니다.

3. 사람의 트리거와 승인 게이트 운영:

• AI가 초안을 빠르게 잡더라도, 중요한 정책 결정과 최종 발행은 사람이 직접 검토하고 승인하는 통제 체계를 구축했습니다.
